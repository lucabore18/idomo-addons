# Add-ons de Idomo para Home Assistant

Idomo instala, conecta y cuida casas inteligentes en Córdoba, Argentina.

| Add-on | Qué hace |
| --- | --- |
| [Idomo](idomo_conector/) | Conecta la casa con Idomo. Solo ejecuta una lista cerrada de herramientas y no abre puertos |

Para agregarlo: en Home Assistant, **Ajustes → Complementos → Tienda de complementos → ⋮ → Repositorios**, y pegá la dirección de este repo.

Este repo tiene solo la ficha del add-on. La imagen se publica ya compilada en GitHub Container Registry.
